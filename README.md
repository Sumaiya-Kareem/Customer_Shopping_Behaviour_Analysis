# Customer_Shopping_Behaviour_Analysis
🛍️ Customer Shopping Behaviour Analysis
📌 Project Overview
This project analyzes customer shopping behaviour using Python and Pandas to uncover purchasing patterns, customer preferences, and business insights from retail transaction data.

The analysis focuses on customer demographics, product categories, purchasing habits, subscription status, payment preferences, and customer review ratings. Through data exploration and visualization, the project identifies trends that can help businesses improve customer engagement and sales performance.

🎯 Objectives
Understand customer purchasing behaviour
Analyze customer demographics and spending patterns
Explore product category performance
Evaluate subscription and loyalty trends
Identify factors influencing purchase decisions
Generate business insights through exploratory data analysis (EDA)
